# Contributing / 参与贡献

Bug reports, suggestions, documentation and code are welcome, in English or Chinese.

- **Feedback:** open an [issue](https://github.com/FlashML-org/FreeVideo/issues) with a short description and the FreeVideo version. A local diagnostic report helps.
- **Pull requests:** explain the change and how you checked it. For performance changes, include before/after measurements with the same settings.

AI-assisted contributions are welcome. Please understand the changes you submit.

Contact: [Discord](https://discord.gg/MsA277cJzZ) · [QQ Group](https://freevideo-community.pages.dev/qq) · [WeChat Group](https://freevideo-community.pages.dev/wechat).

欢迎用中文或英文反馈问题、提出建议、改进文档或提交代码。

- **反馈问题：**在 [Issues](https://github.com/FlashML-org/FreeVideo/issues) 简单说明问题和 FreeVideo 版本。如方便，可附本地诊断报告。
- **提交改动：**说明改了什么、如何验证。性能改动可附相同配置下的前后对比。

欢迎使用 AI 辅助贡献，请理解自己提交的改动。

联系：[Discord](https://discord.gg/MsA277cJzZ) · [QQ 群](https://freevideo-community.pages.dev/qq) · [微信群](https://freevideo-community.pages.dev/wechat)。
